# Lab Safety

- Use VirtualBox Internal Network or Host-only networking with devices you control.
- Do not target campus, work, public Wi-Fi, or third-party networks without explicit authorization.
- Keep active modules disabled by default.
- Use only private IPv4 targets and a domain you control for DNS testing.
- Do not capture or store credentials, cookies, or session tokens.
- Stop active sessions after the test and manually restore any lab changes.
