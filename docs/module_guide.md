# Module Guide

## Read-only / low-impact starting points
- Installation and version check
- Network interface overview
- Bettercap help
- Network discovery

## Controlled lab modules
- ARP lab: requires `BETTERCAP_LAB_MODE=1`, a private IPv4 target, interface, and exact confirmation phrase.
- DNS lab: requires `BETTERCAP_LAB_MODE=1`, a valid lab domain, private redirect IPv4, interface, and exact confirmation phrase.

This project intentionally does not collect credentials, cookies, or session tokens. Wi-Fi monitor-mode and transparent proxy configuration are environment-specific and are not automatically reconfigured by this toolkit.
