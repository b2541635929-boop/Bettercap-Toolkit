# Installation

1. Use Kali Linux or another Linux host you control.
2. Install Python 3.10+, `iproute2`, and Bettercap from trusted official distribution sources.
3. Create a virtual environment and install `requirements.txt`.
4. Run `scripts/check_environment.sh`.
5. Start with `python main.py`.

Bettercap may require elevated permissions for packet operations. Do not run the whole toolkit as root unless required; elevate only the specific authorized operation when possible.
